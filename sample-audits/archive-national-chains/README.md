# archive-national-chains/

The first 3 real audits generated by the pipeline, run against **national chains**:

- Jiffy Lube (Denver, CO)
- Roto-Rooter Plumbing & Water Cleanup (Houston, TX)
- One Hour Heating & Air Conditioning (Phoenix, AZ)

These are **real, un-faked** pipeline outputs. They were valuable for proving the engine is *honest* —
on a near-perfect profile it correctly finds little to flag instead of inventing problems. But a polished
chain profile is **not** the real paying customer, so these audits came back thin and did not test whether
the product is worth $249 to its actual buyer.

They are archived here (not deleted) for reference. The active quality test lives one level up in
`sample-audits/` — 5 audits for realistic, rough, owner-operated single-location businesses. See
`../../JOURNAL.md` and `../../QUALITY_REVIEW.md`.
